# TLP 阶段6：保留方向的真实邻域坐标

实验 `CPSF_TLP_DIRECTIONAL_STAGE6_20261009`；源码父版本为阶段5，保留基准为阶段4确定性旧描述full与skeleton。新方案只在TLP验证，不将它标为其它四任务已经完成的实验。

## 描述定义

从纯点云缓存恢复坐标p。沿用阶段3的几何邻域：仅统计时合并距离<=0.001输入单位的近重合点，最多16个独立支持（含自身），最大邻域半径2×区域半径。以这些真实支持的平均坐标为mu(p)，定义

`d(p) = (p - mu(p)) / 0.5`。

0.5沿用原voxel相对坐标的归一化单位，不根据结果调参；保留原坐标轴，不旋转到PCA主轴，不用特征值替代XYZ。该向量随输入旋转而旋转，平移不变；不能称为旋转不变描述。它编码点相对邻域中心的位移，不等于完整描述所有局部曲率或切向结构。

两个候选：directional_xyz使用[d_x,d_y,d_z,原pf第四维]；directional使用[d_x,d_y,d_z,||d||]。这样区分只改善方向坐标与同步更新相对距离的影响。仍为四维，参数量304897不变。

不足三个不同支持或邻域退化时回退原四维pf，不补造邻居；对称邻域中心仍可产生合法零向量，不为追求非零比例人为偏移。近重合合并仅作用于统计支持，原始每个点的位置仍用于相对邻域中心的位移。原点集合、归属、质量、区域、标签和读出支持不变。

输入单位沿用NREDD缓存；本轮没有完成新的微米标定，不把0.5直接写成已验证的微米。更大邻域位移可使描述幅度大于原voxel内偏移；保留原归一化常数并记录分布，不加裁剪或事后标准化。所有描述来自同细胞表面几何，不读取骨架或标签。

保留确定性索引聚合、新节点对区域读出、动态分辨率、位置／尺度编码、固定残差与任务监督。完整模型始终保留尺度MLP；no_scale只是原定义的显式尺度MLP对照。

共12组：先voxel_full与voxel_skeleton精确重放阶段4，要求80轮损失、权重、62图预测和指标一致；通过后启动两个候选各full、mean_only、no_fusion、no_scale、point共10组。失败停止放行，不放宽断言。旧描述其它对照以带哈希的阶段4冻结参考引用，不计为本轮新训练。

固定seed42、原空间分组train156/val62/test55、80轮、12480优化步、batch1、Adam lr=.001、weight_decay=.001、StepLR20 gamma=.1，保持初始化和逐轮样本顺序。仅最终轮正式验证，不使用测试集，不按验证成绩选checkpoint。

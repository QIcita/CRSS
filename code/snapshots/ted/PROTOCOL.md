# TED / TLP：仅训练配置验证

目的：检验现有完整模型与消融的差距是否受优化配置影响；不预设完整模型必胜，也不按差距最大化选配置。全量报告各配置下的完整模型与消融，再报告各模型拥有相同搜索机会的验证集最好结果。后者属于开发集调参，不作独立测试结论。

## 固定项

seed42、分组训练/验证划分、初始化、每轮样本顺序、Adam、批大小、权重衰减、损失定义与类别权重、原始点描述、位置/尺度与动态分辨率、各模型结构、最终轮评测和判定阈值全部保留。TED 30轮、batch64、weight_decay0.0005，逐事件损失梯度累加不除以batch；TLP 80轮、batch1、weight_decay0.001。

TED 直接使用 20261006 固定残差 NREDD 模型与输入；TLP 使用阶段4确定性聚合与节点对读出，descriptor=voxel。正在进行的阶段6方向描述不混入本轮。两任务继承各自父实现，不能称为跨任务统一的新版本。

训练集/验证集：TED 23967/10762事件；TLP 156/62图。测试集不加载。TED 主指标阳性F1，固定sigmoid-round-argmax；TLP 主指标全部未观测无序节点对的Missing-edge macro AP，保持缺边损失与独立指标核验。

## 配置与队列

基线引用已完成、带哈希的父结果；新增两个独立候选：

|配置|TED|TLP|
|---|---|---|
|baseline（历史引用）|lr0.001，轮e使用0.001/e|lr0.001，每20轮乘0.1|
|lr_half|lr0.0005，其余不变|lr0.0005，其余不变|
|slow_decay|lr0.001，轮e使用0.001/[1+(e−1)/3]|lr0.001，每40轮乘0.1|

每个候选均训练full、mean_only、no_fusion、skeleton、point、no_scale；TED另含no_position。因此TLP12组、TED14组，共26组。无按早期成绩淘汰，无只调完整模型，无延长某一组预算。当前轮不包含其它消融，不能据此声称完整模型超过全部已知变体。

## 工程门禁与执行

新目录CPSF_NREDD_CONFIG_ONLY_20261009保留父源码逐字节副本；父协议、数据manifest、split、参考身份/历史/预测/权重/指标记录SHA256。训练前检查全部13个模型的初始指纹、一个验证样本的父最终输出逐值重放、有限梯度、分组与样本数量，以及两个候选逐轮实际学习率。正式训练逐缓存校验SHA256，并逐轮核对父样本顺序。

新调度器等待阶段6成功完成后才运行GPU门禁并接续训练。若阶段6或门禁失败，停止放行并写明原因。优先TLP，随后TED；最多6路、45秒错峰，GPU至少保留2GiB、每新增任务预留5GiB；RAM至少保留6GiB、每新增任务预留4GiB。资源不够则等待；不覆盖旧缓存、模型、结果或控制器。

评价方式：逐配置公平比较、逐模型等机会搜索上界、最终轮主指标。若仍无法取得完整模型优势，保留结果，承认仅训练配置不足以解释当前差距。

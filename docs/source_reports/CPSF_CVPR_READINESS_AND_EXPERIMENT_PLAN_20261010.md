# CVPR 投稿准备度与实验取舍建议

依据：2026-10-10核验的47项当前默认结果与30项配置探索记录。这里评估现有方法论文的竞争基础和实验组织，不给录用概率，不将方法新颖性视作已经完成相关工作认证。主文篇幅参考已核实的CVPR 2026规则；目标届次投稿时以当届规则为准。

## 1. 判断

有值得冲击CVPR的基础，三个数据集、五个任务的范围已经足够；当前尚不能仅凭内部消融判断其具有成熟的主会竞争力。需要补强的首先是外部竞争性、核心机制的不可替代性和独立评测，而不是增加版本、数据集或消融行数。

支持继续推进的事实：跨人类皮层、果蝇与神经元重建数据；局部区室分类、整细胞回归/分类、节点错误检测、节点对连接预测；已有覆盖、编码、交互、区域错配和上下文对照；TLP方向XYZ有匹配输入描述改进证据。无需为数据集数量引入第四个数据集。

主要风险：

- 目前结果表以同一方法家族的内部对照为主。历史TED-Net/TLP-Net复现来自旧协议，不能直接证明当前空间分组协议下优于外部方法。
- 动态分块、位置编码、MLP残差、层级注意力分别已有成熟背景。需要论证共同区域表示、测度处理与跨尺度对应的具体贡献增量，不能只靠模块命名或两个模态拼接宣称技术新意。这里是可能的审稿质疑，不是经过文献查证的重复性结论。
- 当前不同任务保留不同适配版本；应冻结共享核心和允许变化的输入/读出边界。分别训练及任务特定预测头合理，不要求共享一套权重；涉及交互主干的差异则必须明确并验证。
- 主结果仍是开发验证。CVPR并无统一“必须额外测试集”的机械要求，但当前反复模型选择意味着论文级效果应由冻结后的独立评测支撑。使用确实未参与选择的保留组；历史已暴露的数据不能重新命名为未见测试集。
- TED有已知配置敏感性：lr_half full49.552%略高于mean_only49.520%，但slow_decay skeleton53.415%更高。该事实限制普遍双模态优越性的主张；一个任务的例外不等于整个方法必须推翻。

## 2. 论文主张建议

核心主张：在可变大小的神经元结构上，以尺度感知输入和共同区域对应联合编码骨架拓扑与表面几何，支持不同输出粒度。

将贡献集中为两项机制：

1. 可变分辨率与物理位置/尺度感知表示，解决覆盖与尺度语义。
2. 共同区域上的模态对应和证据保留式交互，解决异质粒度的协同。

层级传播与任务查询读出把二者组成统一架构。方向XYZ目前作为TLP输入适配；确定性聚合和骨架修复是正确性基础；学习率是训练配置。关于高阶超图、任意尺度自适应、零样本迁移的强主张尚无完整证据，采用与实际算子匹配的名称。

## 3. 实验如何分配

以下“必须”是针对本文拟定主张的建议，不是CVPR官方规定的模型数量或实验清单。

| 内容 | 主文建议 | 补充材料 | 是否可不再扩展 |
|---|---|---|---|
| 三数据五任务的最终模型和强外部基线 | 必留主指标；核心效果证据 | 全部次指标、逐类与完整配置 | 不建议删去已有任务以规避不利结果 |
| 骨架对照、mean_only、no_fusion | 关键对照必留；至少覆盖局部/整体、相关数据域 | 完整五任务矩阵与所有已跑对照 | 不要求每个工程变体全五任务重跑 |
| 表面单分支 | H01/FlyWire作为正式模态对照 | TED/TLP作为查询条件诊断，说明样本依赖 | NREDD该项可不追加新的调参搜索 |
| 动态分块vs同预算均匀采样 | 必留，直接支撑第一机制 | thumbnail及更多预算档位 | 不需要很多近似等价的采样算法 |
| 位置/尺度2×2消融 | 保留精简矩阵，至少一个局部和一个整体任务 | 各任务完整矩阵 | 不能只展示单独删除、隐藏双删除的非加性 |
| 区域错配/普通融合对照 | 必留至少一种直接对应检验及强替代融合 | 其余错配种类、更多任务 | 随机错配不是强竞争方法，不能代替强融合基线 |
| 去粗上下文 | 若强调第三层贡献，主文留代表任务 | 完整矩阵 | 若仅称实现选择，可移到补充材料 |
| 跨点数/密度或真实尺寸分层 | 主文至少一组图，直接验证范围 | 更细分组与扰动曲线 | 不必增加新数据集 |
| 时间/显存/输入规模 | 主文简图或表，支持可扩展性 | 预处理、数据加载、纯GPU、端到端分解 | 当前8样本GPU内计时不足以代表端到端成本 |
| 方向XYZ | TLP是主要应用时保留简洁对照或正文明确引用 | 完整描述变体、失败PCA方案 | 无需强制升级成第三项跨数据集创新 |
| 超参数、正则、残差系数、学习率探索 | 关键敏感性正文一句结论 | 所有配置及等搜索机会比较 | 不必穷举大量参数组合 |
| 训练曲线、故障修复、工程验收 | 简述可复现性即可 | 必要实现细节、可复现材料 | 可从论文移除逐版本流水账 |
| 旧门控/旧冻结迁移/历史模型版本 | 一般不占主文 | 仅保留与主张直接相关的探索 | 可省略冗余版本名，原记录仍归档 |
| FlyWire细分类/检索 | 本文若主张粗类多任务编码，可暂不进入 | 若有同协议完整结果可扩展 | 当前不优先增加任务，避免分散主线 |

正文不能因为某一结果改变核心判断就把它藏进补充材料。TED最强骨架配置需要在强基线/调参结果中体现，并在正文说明例外；完整调参表可在补充材料。H01位置/尺度非加性在正文中保留解释，完整2×2表可视布局安排。

## 4. 优先补哪些外部基线

需要补“竞争方法”，而不仅是继续删除自己的模块。最终具体方法应经过针对性相关工作检索及实现可适配性核验；以下为基线家族设计，不是已完成结果。

| 基线家族 | 最少需要回答的问题 | 合适位置 |
|---|---|---|
| 原任务专用方法 | 与TED-Net/TLP-Net等任务方法在同划分、同可见输入、同指标下相比如何 | NREDD主结果表；保留原方法身份 |
| 强骨架图编码器 | 我们的骨架分支是否只是较弱的图编码器 | 适用任务的GNN/图Transformer或神经元形态图方法 |
| 强点云编码器 | 表面收益是否来自点编码器能力差异 | H01/FlyWire，NREDD使用同查询条件口径 |
| 简洁强融合 | 独立强编码器＋拼接/平均或常规交叉注意力能否达到同样结果 | 关键任务；隔离共同区域交互的必要性 |
| 最接近的联合几何方法 | 本文相对已有关系建模究竟改变了什么 | 在其输入假设适用的任务上，明确适配 |

预算充足时使用约4—6个有解释力的代表方法，比十几个弱旧基线有价值；数量不是门槛。不是所有外部方法都天然适用于五任务；对不适用方法标明范围，不强行包装成原作者模型。区分原输入下的方法复现和统一输入下的编码器替换。

完整模型和所有比较方法保留相同数据隔离、标签可见性、主指标、合理训练/调参机会。可保留seed42，不把多seed作为本项目推进门槛；完整数据划分、共同预算与有说服力的机制对照更紧迫。

## 5. 最有价值的新增机制实验

A. 一次训练、跨点预算/采样密度测试。在原始几何支持范围内改变采样点数，保持坐标、标签与对象身份；比较full、同预算均匀采样及强基线。优先FlyWire与H01整体，覆盖真实细胞尺寸分层。这直接验证可变分辨率能力。不要把任意缩放生物尺寸都假定为标签不变，也不要随意删骨架边却保持TED/TLP目标集合不变。

B. 共同区域 vs 简单融合/标准交叉注意力。在相同输入描述、点预算、输出读出下比较，计算成本同时报告。mean_only与no_fusion是必要内部对照，但不能完全替代这个外部竞争性检验。

C. 质量—计算预算关系。至少报告点数/区域数、峰值显存、预处理和推理耗时；分开GPU驻留纯计算与端到端。已有固定8样本计时可以继续保留作组件测量，需扩充尺寸覆盖以论证可扩展性。

若保留跨数据集共享权重或零样本泛化主张，才需要相应跨域迁移实验。当前定位为统一架构分别监督训练，可将迁移列为扩展，不必为凑CVPR实验而强行新增。

## 6. 八页主文的一种可行布局

参考CVPR 2026官方：主文8页（含图表），仅参考文献可增加页数；补充材料可选，审稿人无义务阅读。下列仅为篇幅建议：

| 部分 | 页数预算 |
|---|---:|
| 标题、摘要、引言与问题图 | 1.25 |
| 相关工作 | 0.50 |
| 方法与架构图 | 2.25 |
| 数据/协议、主比较、核心消融、机制/效率图 | 3.50 |
| 局限与结论 | 0.50 |
| 合计 | 8.00 |

实验可组织为：一张三数据五任务主结果表；一张关键交互消融表；一张采样/编码精简消融表；一幅跨点预算的性能与开销曲线；一组成功和失败的空间对应可视化。协议和数据规模以紧凑文本或小表交代。若宽表不可读，拆成两个任务组，不为合表缩小到难以阅读。

H01整体训练80/验证24细胞，适合作为功能相关回归的互补证据，不宜单独承载普遍形态到功能推断的大主张。FlyWire粗类和NREDD重建任务承担主要大样本/结构任务证据；H01局部补细尺度语义。

## 7. 执行优先级

1. 冻结最终共享核心和任务适配清单，明确独立评测方案；将已有训练探索如实保留。
2. 优先同协议强基线、简单强融合对照，再补能直接回答尺度/对应机制的实验；其重要性高于继续增加内部版本。
3. 有选择地补当前默认TED/TLP缺失消融。完整版本矩阵可放补充材料；不要求每一项消融都覆盖五任务。
4. 形成独立评测后的主表、尺度/效率曲线及失败分析，再评估投稿说服力。

现阶段判断：值得以CVPR为目标收敛；不需要新增数据集来增加体量。能否形成有竞争力的投稿，取决于外部基线、具体技术差异和独立评测是否支持主张，不能仅由47项结果或预期排序决定。

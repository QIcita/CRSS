# H01归一化、输入范围与官方基线复评审查（2026-10-11）

## 当前样本统计与数据泄漏的边界

当前细胞自身的均值、方差通常不构成数据泄漏：它们是推理时可观测输入的确定性函数。这里使用的是原生BatchNorm的当前样本统计，保留已训练的仿射参数，关闭跨样本running统计；其他层保持eval，且不更新任何学习参数。它与InstanceNorm/GraphNorm的样本内统计原则类似，但数值实现仍是原生BatchNorm，并不是替换成这两种层。

范围由任务输入决定：FlyWire整细胞分类、H01整体任务可以使用当前整细胞的输入点／节点；H01局部任务只能使用当前事件所提供的局部片段。不能把多个验证细胞混在一起构建共享统计，不能保留测试样本更新的统计供后续样本使用，也不能利用标签更新参数。局部任务若偷偷引入未声明的完整细胞几何，属于输入协议改变，不能称为同输入比较。

这次cell-BN是显式的任务适配规则，不是作者默认running-BN推理，也不是原正式协议的原始成绩。验证集可以用于发现和修正适配问题；规则必须在最终独立测试前冻结，不能用测试成绩在原BN／cell-BN之间挑选。此次复评仅使用训练探针和开发验证集，没有读取测试集。

H01同样存在统计不一致的质量问题，其中Exphormer整体任务最明显：MAE由0.340695降至0.060130。仅固定权重改变推理统计就能恢复大部分表现，因此此前明显偏低的基线不能作为可靠能力比较。LitePT局部也由0.573502提升至0.634839，缩小了与完整模型的差距。

固定训练探针也支持这个判断：局部按seed42每类取10个事件，共30个，Exphormer的训练探针F1由0.350000恢复到1.000000；整体使用全部80个训练细胞，其MAE由0.280953恢复到0.008904。OctFormer整体训练MAE由0.111127恢复到0.001390，PointMamba由0.035034恢复到0.002395。探针不作为验证成绩，也没有重新训练；它们说明原推理模式对已训练样本也存在明显失真。

影响并不一致：PointMamba局部几乎不变；OctFormer局部由0.502671降至0.472227。所有变化统一列出，没有按验证成绩选择保留哪种方式，不能声称cell-BN必然改善每个任务。保留的完整模型在H01两个任务上仍优于这五个统一cell-BN适配基线；这个结论不扩展到FlyWire，此前FlyWire的PointMamba复评已经略高于完整模型。

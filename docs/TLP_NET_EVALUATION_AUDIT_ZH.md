# TLP-Net任务适配与评测范围审计

日期：2026-10-20。本轮使用现有权重与开发集预测，未修改数据、模型、损失、权重和正式指标，未启动新训练。原有测试集诊断仅按历史证据单列，不用于迭代或选择。

## 结论

**当前缺边AP的计算未发现实现错误；此前把适配后的TLP-Net与原论文AP混读，以及没有充分披露训练目标和任务解码头的差异，属于比较设定与报告层面的问题。** 当前0.108438不能称为“原论文TLP-Net只复现到10.84%”，也不能据此宣称在论文原任务上超越TLP-Net。

如果研究问题是恢复输入中不存在的连接，主指标应保留全部未观察无序节点对的Missing-edge Macro-AP。若研究问题是复现NREDD论文的完整重建系统，则必须另报官方训练目标、完整邻接兼容指标及Rule后处理；两个问题不能合并成一个AP。

## 本轮开发集独立检查

- 62张开发图、1,146,183个未观察无序节点对、283条缺失正边，62张图均有缺边正例。宏平均对每图等权，微平均汇总全部节点对。
- 掩码独立构造为`i < j AND NOT observed[i,j]`。observed为原始布尔邻接，不是归一化GCN邻接；不含对角线或已有边，没有距离/top-k候选筛选或负例抽样。
- TLP-Net适配、官方损失对照、SGFormer、Polynormer共248份开发预测文件逐图核对target/observed、有限分数、对称性；重算Macro-AP、Micro-AP及完整邻接AP，与存档精确一致。R28的62份预测target/observed也与同一源逐元素相同。
- 四组末轮权重SHA与正式metrics记录相同，均为80轮、12,480次更新。官方损失对照与适配版初始参数摘要及80轮样本次序完全相同。
- 六个冻结官方模型/预处理/训练源文件重新与NREDD提交`99afba251f4933bcf11c629df3c1929d9e6e8524`比对，逐字一致。核查使用冻结vendor与Git对象，不能用服务器可变工作区代替。

本轮没有重新前向全部模型或重读全部原始SPE图像：这是对已落盘预测和当前文件身份的核查。此前2026-10-15审计曾验证全273图XYZ/邻接/target/observed与官方函数一致、全部训练/开发图包装前向与直接调用相同，原始SPE复读仅覆盖训练图节点数最小/中位/最大的3图。两类证据不能混称为本轮全量原始图像审计。

## 为什么当前TLP-Net偏低

**有直接证据的因素：训练与评价目标改变。** 官方目标为整个N×N邻接，含已有边与对角线；当前适配只监督未观察无序节点对。训练集27,823条已观察正确边不再作为正例参与损失，只剩778条缺失正边和4,035,346个未观察节点对。恢复官方目标显著改善完整邻接重建，但缺边指标反而更低。当前缺边适配实际上改善了原生目标在该新任务上的能力，却仍然较弱。

**有直接证据的因素：完整邻接指标受到已有连接支配。** 在同一62图开发集上，完全不预测新边、只复制observed，就有完整邻接Macro-AP **0.965439**。同一常数分数在缺边任务的Macro-AP仅 **0.000639**；微平均正例率为283/1,146,183≈0.02469%。这不是让主指标改回完整邻接的理由，而是必须区分“重建已有连接”和“发现缺失连接”的理由。输入已有邻接本身不是常规训练/测试泄漏，但把已有边重建成绩当作新边恢复能力会夸大任务完成程度。

**代码支持、尚未单独证实的因素：解码器和几何信息利用不同。** 官方TLP-Net使用`z @ z.T`内积解码；当前SGFormer/Polynormer适配器使用节点和/差/积、全局上下文、节点对位移与距离的可学习任务头。R28也有独立的方向XYZ/走廊对读出。因此现在是完整适配系统比较，不是“只替换骨架编码器”的同头对照，不能把差距全部归因于TLP-Net主干。当前没有通过同头重训证明内积解码器是唯一或主要原因。

**不是已定位的主因：错序或sigmoid排序。** 此前固定适配权重的开发集logit AP与sigmoid AP相同；训练集缺边Macro-AP也只有0.140978。配合本轮掩码、标签及文件身份检查，证据不支持“只是评测错位、阈值0.99或末端sigmoid饱和”的解释。AP本身不依赖0.99分类阈值；这不排除训练期数值或优化影响。

**未包含的系统部分：Rule。** 原论文将TLP-Net与TLP-Net+Rule分开报告。官方`Rec_adj`包含端点/边界、各向异性距离、半径、角度、已有连接和贪心连接等规则，返回恢复后的二值邻接。当前主表不包含它；不能把“无Rule神经网络”的排名宣称成超过论文完整修复系统，也不能把Rule的二值输出冒充论文未公开的连续排序分数。若后续评Rule，需要独立预注册，并在相同开发协议下向各方法提供一致规则，报告全缺边范围指标、覆盖率与阈值型指标。

## 与论文结果的关系：历史证据，非本轮测试反馈

论文为*A multimodal fusion model based on graph convolutional network for 3D neural morphology optimization*，Pattern Recognition 177 (2026),113267，DOI:10.1016/j.patcog.2026.113267。原官方划分192训练/81测试；当前空间划分156训练/62开发/55测试。发布代码weight decay为1e-3，论文写1e-4；当前用发布代码默认。因此即使恢复原损失，也不是原论文全部协议的严格重现。

2026-10-15留存的作者发布权重诊断：在原81测试图的完整邻接去对角线口径AP为 **0.775098**，与论文 **0.7751** 对齐；相同权重相同图在缺边范围AP为 **0.014687**。论文另列TLP-Net+Rule AP **0.9751**。这些旧诊断说明论文主指标可复现；本轮未重跑这81图，不使用其成绩决定新方案。

## 已落实的报告修正与后续边界

1. 当前主表将方法标为“TLP-Net（Pattern Recognition’26）†”，脚注明确“缺边目标适配、无Rule”；九个baseline全部补齐真实刊物/会议和年份，保留scratch/adapted限定。
2. 保留全部未观察无序对AP作为修复任务主指标；恢复官方损失的结果在本审计单列，附同一开发集的完整邻接兼容指标。不会为了接近论文数值而换成易得高分的完整邻接AP。
3. 后续若归因编码器优势，应增加相同解码头/相同几何输入的受控对照；若比较论文修复系统，应独立评价Rule。两项尚未实施，不在本轮报告中伪装已解决。
4. 现有空间组不交叉，但数据有历史项目接触；本轮检查不构成源神经元级无泄漏证明或全新独立测试证据。单seed42按现有约定用于开发比较，不宣称统计显著或普遍SOTA。尚未做同等搜索预算的超参数优化，不能断言已给每个baseline找到最优配置。

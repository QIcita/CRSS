# C版论文实验方案：三张机制消融表与两组可视化

2026-11-01。设计对象是已经完成三任务训练的 **C版 `regional_scaled_pi`**。PI根条带／统一栅格、PI公共密度／加权残差是独立候选，均不混入本方案的Full。当前范围固定为H01整体、FlyWire粗分类和MICrONS。

本轮交付是消融与可视化的可执行设计、去重任务账本和待填结果表；未把设计写成已经完成的实验。PTv3–MICrONS补跑另行执行，不属于消融矩阵。

## 1. 论文证据结构

正文形成 **1张外部方法主比较表＋3张机制消融表＋2组多面板可视化**。三张机制表分别回答：

1. **SMM：分支结构与全局持久性摘要，是否需要在模态内部交互？**区别信息是否存在、交互是否存在和PI可学习编码的贡献。
2. **CMM：局部形态基底、邻域和层级视图是否互补？联合交互是否超出简单相加？**把D/C作为同一个联合上下文模块的内部路径检验，不隐藏单路径可能负收益的结果。
3. **RCM：同尺度与跨尺度的模态交互是否互补？条件聚合及直接信息保留是否必要？**把“有额外参数”和“保留了所需信息关系”分开讨论。

可视化一观察MICrONS区域预测是否在空间上更接近真实分布；可视化二观察FlyWire的Macro-F1优势来自哪些类别、错误如何改变，并展示对应的区域聚合。它们不能保证画出优势；若存在取舍，图中如实保留。

这些是依据当前代码与任务制定的实验，不声称照搬某篇顶会论文的具体表图。`oral-paper-skill`所采用的实践是“主张对应证据”“比较必须回答一个决定”：例如 *Training on the Test Task Confounds Evaluation and Emergence*（[ICLR 2025摘要S6–S8](https://iclr.cc/virtual/2025/oral/31791)）强调比较中的任务训练暴露，本方案据此固定训练暴露与选择规则；该来源仅检查了技能中存储的摘要，不据此归因原论文的实验细节。

## 4. 表二：CMM联合上下文的互补与交互（5行）

固定SMM、RCM、细patch载体、原密集邻域和层级映射。H是细patch形态基底；D是邻域视图；C̃是按H校准幅度后的层级视图。此处C̃指内部特征，不是模型版本名。

| ID | 邻域D | 层级C̃ | 三路成对交互 | 实际输出 |
|---|---|---|---|---|
| P0 `cmm_anchor_only` | 关闭 | 关闭 | 关闭 | H |
| P1 `cmm_neighborhood` | 保留 | 关闭 | 关闭 | H＋0.1D |
| P2 `cmm_hierarchy` | 关闭 | 保留 | 关闭 | H＋0.1C̃ |
| P3 `cmm_additive` | 保留 | 保留 | 关闭 | H＋0.1D＋0.1C̃ |
| F `full` | 保留 | 保留 | 保留 | 原C的完整CMM |

P0/P1/P2/P3构成内部两路径2×2；F对P3单独检验成对交互。以效用U表示各任务指标（F1取正，MAE/deviance取负），可计算描述性交互量：

`I_DC = U(P3) - U(P1) - U(P2) + U(P0)`。

它是在本冻结训练协议下的描述性差值，不自动证明统计显著或普遍协同。即使P1/P2低于P0，只要如实保留结果，仍能用P3与F判断两种上下文是否在组合时有用；不得为了叙事删除单路径行。

实现必须保持H、D、C̃的原运算和系数：`C̃=RMS(stopgrad(H))/RMS(C)×C`。关闭层级路径时D仍必须独立执行；关闭邻域路径不能改变hierarchy映射。P0/P1/P2/P3都关闭全部三路成对交互，而不是保留某个单路径与H的交互，否则2×2不再只对应D/C存在性。

只将交互开关设false还不能得到P0–P2，必须分别控制`encode_hierarchy`、`neighborhood_view().encode_patches`和输出项。关闭的路径不执行，不通过随机调用消耗改变保留路径的初值。训练中仍记录原固定样本顺序；如执行路径改变随机数消耗，要记录而非声称随机轨迹完全相同。

不在本表扫描patch尺寸、邻域半径、关联阈值或Utonia深度。由此减少任务配置和几何支持一起变化的混杂。

实现锚点：`tools/cpsf_r38_joint_context/unit.py::ContextualMorphology/JointContext`、`tools/cpsf_cmm_pair_fusion/operator.py::PairFusion`。

## 5. 表三：RCM同尺度、跨尺度交互与信息保留（6行）

固定完整SMM和CMM、骨架—patch关联、区域质量、几何编码、区域processor与最终读出。

| ID | 自适应聚合 | 同尺度交互 | 跨尺度交互 | 直接模态基底 | 核心对比 |
|---|---|---|---|---|---|
| R0 `rcm_prior_pool` | 改为原几何／质量先验 | 保留 | 保留 | 保留 | F对R0：可学习聚合是否超过先验 |
| R1 `rcm_no_same_scale` | 保留 | 关闭 | 保留 | 保留 | F对R1：同尺度交互的条件增益 |
| R2 `rcm_no_cross_scale` | 保留 | 保留 | 关闭 | 保留 | F对R2：跨尺度交互的条件增益 |
| R3 `rcm_no_scale_interaction` | 保留 | 关闭 | 关闭 | 保留 | 与R1/R2/F构成2×2 |
| R4 `rcm_no_direct_base` | 保留 | 保留 | 保留 | 仅去最终直达项 | F对R4：直接信息保留是否必要 |
| F `full` | 保留 | 保留 | 保留 | 保留 | 原C |

精确操作：

- **R0**：令聚合权重`alpha=prior=pw×patch_mass/surface_mass`，绕过query/key及score_geometry的权重打分。保留value、relation、content_gate、所有交互和mask。它检验“学习式内容＋几何打分整体”超出已有先验的贡献，**不把结果单独归因于骨架query**；content gate仍是骨架条件化。
- **R1**：同时令`local_pair`输出的ds/dp和`global_pair`输出的dsg/dpg为零；后续两条跨尺度路径正常执行。这里同尺度包括局部↔局部、全局↔全局。
- **R2**：仅跳过`cross_skeleton(local_s,global_p)`及`cross_surface(local_p,global_s)`的输出cs/cp；局部与全局同尺度交互保留。
- **R3**：跳过R1与R2所列全部交互；仍有条件表面聚合、门控、关系编码、两模态区域平均和processor，因此准确名称是“去尺度交互”，不是“完全无RCM”或“无多模态融合”。
- **R4**：所有交互仍以原s、p及局部增强状态为输入；仅在最终区域拼合时，将`(s+ds+cs,p+dp+cp)`改成`(ds+cs,dp+cp)`。几何项、dsg/dpg、mask、分母、processor和readout完全保留。这样检验最终直达信息，而不是先清零s/p从而把交互输入也删除。由于p包含relation，删除p的直达项也包含其直接关系信息，论文须按这个整体解释。

R3/R1/R2/F构成同尺度×跨尺度2×2。描述性交互量为：`I_scale=U(F)-U(R1)-U(R2)+U(R3)`。若只在MICrONS有效，就限制跨尺度互补结论的任务范围；不要求每个机制在每项任务都独立改善。

实现锚点：`tools/cpsf_h01_progressive_repair/regional.py::RegionalCoupling.forward`；MICrONS必须继续从`trace['processed'][query_index]`读出，不能为了接口方便复制整细胞向量到全部区域。

## 6. 可视化实验一：MICrONS区域分布与空间误差

**要回答的问题：** C的deviance优势是否对应真实区域分布的改善，还是只调整了总量？

比较C、最强外部点云baseline Utonia及R3。Utonia和C的已有完整预测可先用于图的主比较，R3待完成本次消融后按固定槽位补入。采用同一80个测试细胞、同一241,249个区域，不新增训练。

一组图组织为：

- **a：区域三维图。**每个案例依次展示真实计数密度`y/length`、Utonia、R3、C的`mu/length`。使用相同骨架、区域编号、相机、视野和颜色范围；画出的骨架/区域不重建标签。两处局部放大框由输入几何确定，不能在看到误差后只挑优势区域。
- **b：同一几何上的偏差图。**画`d(y,mu)=2[y log(y/mu)-(y-mu)]`，y=0使用2mu。也展示`(mu-y)/length`的有符号误差，避免总看“颜色更平滑”。
- **c：全80细胞配对散点。**横轴Utonia细胞平均deviance，纵轴C；画y=x，报告C更好／相同／更差的细胞数，并画`D_Utonia-D_C`的分布。所有80例保留；不把241,249个相关区域当独立细胞样本。
- **d：总量与分布的取舍。**同图显示两模型总计数绝对误差及JSD的配对分布。当前C的总计数MAE落后，应明确显示，不能用更好的deviance掩盖。

主案例按测试输入的`query_regions`排序（并列按root_id），固定取25%、50%、75%位置最近的三个细胞，不读取标签或误差选样。追加一个明确标注的“最大退步案例”：按`D_C-D_Utonia`最大选择，作为结果后的失败分析；它不参与修改模型或前三例选择。附录输出全部80例索引及配对统计，支持追溯。

密度色标范围在训练集真实密度分布上固定，采用log1p显示并标明饱和区域占比；同一案例各列绝不独立归一化。测试只用于最终展示和预定义统计。配套导出PDF/SVG、300dpi PNG、逐细胞指标JSON和逐区域表，包含模型checkpoint与预测文件SHA-256。

**支持范围：**能支持空间预测与分布误差的经验改善，不能证明形态导致突触形成，也不能从颜色推断模型发现了真实生物机制。

## 7. 可视化实验二：FlyWire类别收益、错误转移与区域聚合

**要回答的问题：** C的Macro-F1提升来自哪些类别？骨架—表面区域交互怎样改变分类结果？是否牺牲了占比大的类别？

比较C、最强外部GraPHFormer官方特征／分类头适配，以及S1、P0、R3三个有明确机制含义的消融。S1/P0/R3来自三张表，不额外训练“画图专用”模型。

一组图组织为：

- **a：六类别F1和样本数。**全1,922个开发样本计算每类F1、precision、recall和support，正文画F1及相对baseline的增益；不只画改善的类别。Macro-F1与Accuracy同时标明，解释均衡类别收益与整体正确率的差异。
- **b：错误转移。**画C与GraPHFormer的行归一化混淆矩阵及差值，并保留原始计数；汇总“双方正确／仅C正确／仅baseline正确／双方错误”。不能用总体正确率替换既定Macro-F1主指标。
- **c：固定规则的配对案例。**从“仅C正确”和“仅baseline正确”两组分别按`SHA256(root_id)`最小值选一例（组非空时）；同时展示一个正确例和一个退步例。展示完整形态、PI、模型预测及真实类别。这是明确按结果分组的示例分析，不声称无条件代表整体样本。
- **d：对应区域的聚合视图。**在同一原始关联边上画质量先验prior、C的alpha及`alpha/prior`，标明固定选中的区域和候选patch。区域按输入几何规则选取：最长非空骨架分支的中位弧长区域，候选边不重连、不按注意力挑区域；如果无表面关联，则明确展示“无关联”，不挑另一处替换。

区域热图是聚合算子的行为证据，**attention不是重要性或因果解释**。它要与全量类别指标、错误转移及R3匹配重训相互印证；不把一幅热图当作交互机制被证明。对不存在的严格branch内区域差异不进行美化，现有共享分支状态如实展示。

不把独立拟合的t-SNE/UMAP图“看起来更分离”作为主证据，也不添加扰动训练、重新采样或测试集挑超参数。图导出PDF/SVG、300dpi PNG；同时保存1,922例key、真值、预测、六类顺序、混淆矩阵、配对分组、案例选择规则与alpha/prior原始数组。

## 9. 最少必要验收

- Full等价性：原源码／初始state摘要、代表与极端训练样本输出、真实区域读出和共有梯度；额外用已训练权重只做接口核验，不用其初始化消融训练。
- 模态路径：S0没有PI值进入任何骨架全局/区域路径；S1仍有真实PI编码；P1的D确实独立执行；P2的C保持原映射；保留路径的有效梯度在可丢弃两步后检查。
- RCM路径：R0每个有表面区域的alpha归一为1；R1/R2切断准确路径；R4交互输入不变且只删除末端直达项；原mask、质量、区域编号、query_index、目标、length、分母不变。
- 保存完整终态或明确失败；禁止用中间最优值填补正式结果，禁止按测试表现选择重试。只修明确实现或资源错误，并记录修订身份。
- 效率在同硬件、同冻结训练样本列表、同精度测量，区分有效参数、峰值显存、推理时延与总训练时间；不将删除模块后的加速归因于更高效实现。
